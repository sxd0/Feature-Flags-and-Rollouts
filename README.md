# Feature-Flags-and-Rollouts

Мини-платформа: фичефлаги, таргетинг, progressive rollout, быстрый kill switch, аудит, события, realtime и оркестрация длинных процессов.

## Зачем
Разделяем “выложить код” и “включить фичу в проде”. Это даёт:
- безопасные релизы и быстрый откат без деплоя
- постепенное включение с контролем метрик
- таргетинг по сегментам/атрибутам
- аудит изменений

## Архитектурная идея
- **Control Plane** (write-heavy): управление флагами/правилами/роллаутами, аудит, источник истины
- **Data Plane** (read-heavy): быстрый evaluate флагов для `user_id`, кэш, горизонтальный скейл

## Текущий статус (MVP foundation)
- FastAPI `control_api` с `/health`
- тесты (pytest + httpx ASGI transport)
- ruff + mypy
- Poetry монорепо структура
